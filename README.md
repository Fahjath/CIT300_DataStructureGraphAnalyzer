# CIT300_DataStructureGraphAnalyzer

## Data Structure and Graph Performance Analyzer

### Project Description

This project is a Java-based console application developed for the
CIT300 Data Structures and Algorithms module.

The system demonstrates practical implementations of data structures,
searching algorithms, graph algorithms, and performance/complexity
analysis through an integrated menu-driven console application.

The application includes: - Array - Stack - Queue - Linked List -
Searching - Graph - Performance / Complexity Analysis

### Performance / Complexity

The application provides complexity information for relevant operations,
including:

-   Array Search: O(n)
-   Array Delete: O(n)
-   Stack Push: O(1)
-   Stack Pop: O(1)
-   Stack Peek: O(1)
-   Queue Enqueue: O(1)
-   Queue Dequeue: O(1)
-   Queue Peek: O(1)
-   Linked List Search: O(n)
-   Linked List Delete: O(n)
-   Linked List Insert at End: O(n)
-   Linear Search: O(n)
-   Binary Search: O(log n)
-   Graph BFS: O(V + E)
-   Graph DFS: O(V + E)

## How to Run

1.  Open the project in Eclipse IDE.
2.  Open `src/app/Main.java`.
3.  Run `Main.java` as a Java Application.
4.  Use the console main menu to select the required operation.
5.  Follow the instructions displayed by the program.
